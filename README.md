# BigReal Library

The BigReal library provides the ability to work with numbers of arbitrary precision. It supports basic arithmetic operations and can be used for tasks requiring high precision, such as calculating Pi.

# How to build/test/delete this library

```bash
# Build the project
make

# Build and run test set
make test

# Build and run pi computation example
make pi

# Rebuild library
make rebuild

# Delete temporary files
make clean
```
